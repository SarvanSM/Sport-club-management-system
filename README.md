# 🏆 Sport Club Management System

A web-based **Sport Club Management System** developed using **PHP, MySQL, HTML, CSS, and JavaScript** to manage club members, memberships, payments, and administrative tasks.

---

## 🚀 Features

- 👤 Member Registration
- 🔐 Secure Login System
- 🏋️ Membership Management
- 💳 Payment Management
- 📅 Routine Management
- 📊 Admin Dashboard
- 📈 Reports
- ❤️ Health Status Management

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## ⚙ Installation

1. Download or clone this repository.
2. Install XAMPP.
3. Copy the project folder into:

```
xampp/htdocs/
```

4. Start:

- Apache
- MySQL

5. Import

```
sports_club_db.sql
```

using phpMyAdmin.

6. Open your browser.

```
http://localhost/Sport-club-management-system/
